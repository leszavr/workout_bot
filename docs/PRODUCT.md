# Product definition

## Цель

Создать персональный сервис подготовки программ тренировок: пользователь сообщает цели, опыт, условия и ограничения; система формирует структурированную программу из контролируемого каталога упражнений и доставляет её в удобном виде.

## Текущий пользовательский путь

`/start → анкета → review → confirm → profile finalization → filtering → safety → generation → validation → storage → HTML → Telegram`

Основная стратегия генерации по умолчанию: `AI → deterministic fallback`.

## Принципы

- AI не является единственным источником контроля качества.
- AI получает ограниченный generation context.
- Выход генератора проходит независимую validation.
- Исторические версии программ не перезаписываются.
- Ошибка доставки не должна повторно запускать генерацию.
- Safety rules — технический механизм отбора движений, а не медицинская диагностика.

## Текущий MVP

MVP заканчивается доставкой персональной программы в Telegram и возможностью просмотреть сущности через внутреннюю админку.

## Следующая продуктовая граница

Следующая значимая версия должна добавить цикл:

`получил программу → выполнил тренировку → оставил feedback → система обновила модель пользователя → предложила корректировку`

Это важнее новых AI-функций, потому что создаёт накопление полезной истории и персонализацию.

## Не входит в текущий MVP

- медицинская диагностика;
- обещания безопасности при конкретных заболеваниях;
- полноценный AI-чат тренер;
- платежи и тарифы.
