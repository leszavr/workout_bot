# Personal VPN на Windows — настройка

Хост: `HOME-PC\svv`. Файлы подготовлены в `C:\Users\svv\vpn\`, там же
`START-HERE.txt` с кратким вариантом этой инструкции.

| Файл | Что это |
|---|---|
| `amneziawg-amd64-3.1.0.msi` | установщик AmneziaWG — **начните с него** |
| `awg-personal.conf` | конфиг AmneziaWG (рекомендуется) |
| `wg-personal.conf` | конфиг WireGuard (резервный вариант) |
| `wstunnel.exe` | TLS-транспорт для резервного варианта |
| `start-vpn.cmd` | запуск транспорта |

Есть два рабочих способа. Оба проверены на реальном сетевом пути этой машины.

## Почему не «просто WireGuard»

Ваш провайдер распознаёт WireGuard **по поведению потока** и обрывает его через
несколько секунд. Замерено на этом же пути: handshake проходит, 3–8 секунд
трафик идёт, дальше тишина при живом `wg show`. Порт, размер пакетов, форма
payload и версия IP не помогают — проверялось отдельными тестами (детали в
`EU_VPN_HUB_REPORT.md`, §9).

Отсюда два варианта обхода:

| | AmneziaWG | WireGuard + wstunnel |
|---|---|---|
| Шагов при запуске | 1 (только подключиться) | 2 (транспорт, затем туннель) |
| Транспорт | UDP напрямую на узел | TLS поверх IPv6 TCP/443 |
| Как обходит DPI | обфускация handshake | маскировка под HTTPS |
| Оверхед | нет | TCP-over-TCP |
| Зависит от IPv6 | нет | да |
| Клиент | отдельный (MSI в комплекте) | штатный WireGuard |

**Рекомендуется AmneziaWG:** один шаг вместо двух, без TCP-оверхеда и без
зависимости от IPv6. Криптография у него та же, что у WireGuard — это форк с
обфускацией handshake, а не другой протокол.

# Вариант 1 (рекомендуется): AmneziaWG

Зона на узле: `10.10.30.0/24`, UDP/51822. Peer `windows-pc` — `10.10.30.2`,
собственные ключи и preshared-ключ, не пересекающиеся ни с WireGuard-зоной, ни с
Workout-туннелем.

## Шаг 1. Установить клиент

Двойной клик на `C:\Users\svv\vpn\amneziawg-amd64-3.1.0.msi`. Нужны права
администратора — один раз, при установке.

Интерфейс почти идентичен WireGuard for Windows: это его форк.

## Шаг 2. Импортировать туннель

AmneziaWG → **Импорт туннелей из файла** → `C:\Users\svv\vpn\awg-personal.conf`.

## Шаг 3. Подключиться

Кнопка **Подключиться**. Проверка:

```powershell
(Invoke-WebRequest https://api.ipify.org -UseBasicParsing).Content
# должно быть 31.58.181.202
```

Больше ничего запускать не нужно: `wstunnel.exe` и `start-vpn.cmd` для этого
варианта не используются.

## Параметры обфускации

В конфиге есть блок `Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`. Это и есть
обфускация: `Jc` мусорных пакетов перед handshake, `S1`/`S2` — размеры
обфусцированных пакетов handshake, `H1`–`H4` — магические заголовки вместо
фиксированных типов сообщений WireGuard.

Значения должны совпадать с сервером **байт в байт**, иначе handshake не
пройдёт. Не меняйте их вручную; при необходимости смены генерируйте новые
одновременно на узле и на всех клиентах.

# Вариант 2 (резервный): WireGuard + wstunnel

Нужен, если AmneziaWG почему-то не заработает. Зона `10.10.20.0/24`, peer
`windows-pc` — `10.10.20.4`.

WireGuard подключается не к узлу, а к `127.0.0.1:51821`, где слушает
`wstunnel.exe`, который заворачивает трафик в TLS поверх IPv6 TCP/443.

## Шаг 1. Установить WireGuard for Windows

```powershell
winget install --id WireGuard.WireGuard
```

или установщик с https://www.wireguard.com/install/

## Шаг 2. Запустить транспорт

Двойной клик на `start-vpn.cmd`. **Окно не закрывать**, пока нужен VPN. Права
администратора не нужны.

## Шаг 3. Импортировать туннель

WireGuard → **Импорт туннелей из файла** → `wg-personal.conf`.

## Шаг 4. Подключиться

Кнопка **Подключиться**, затем та же проверка через `api.ipify.org`.

Порядок обязателен: сначала `start-vpn.cmd`, потом WireGuard. Иначе туннелю
некуда подключаться.

## Отключение

Кнопка **Отключиться**, затем закрыть окно `start-vpn.cmd`.

# Общее для обоих вариантов

## Взаимодействие с nekoray-tun

Пока `nekoray-tun` активен, он остаётся в маршрутах, и часть трафика может идти
через него: у него свой TUN-интерфейс и свои метрики. Два full-tunnel VPN всегда
конкурируют за default route — это не дефект конфигурации.

Если нужен именно EU-выход: отключить nekoray, затем подключить VPN.

Если nekoray нужен постоянно (например, для доступа к моделям) — сделайте
personal VPN частичным, см. следующий раздел. Тогда конфликта не будет.

Отдельно: `wstunnel.exe` из варианта 2 маршруты не меняет и с nekoray не
конфликтует; конфликт возникает только при подключении самого туннеля.

## Split tunnel вместо full tunnel

Если через EU нужен не весь трафик, замените в конфиге

```ini
AllowedIPs = 0.0.0.0/0
```

на список нужных сетей. Только Telegram:

```ini
AllowedIPs = 149.154.160.0/20, 91.108.4.0/22, 91.108.8.0/22, 91.108.12.0/22, 91.108.16.0/22, 91.108.56.0/22, 95.161.64.0/20
```

Локальная сеть, nekoray и обычный интернет останутся как были. Минус тот же, что
описан в основном отчёте: список адресов ломается, если сервис их сменит.

Для «весь интернет, кроме локальной сети» подойдёт набор из 40 подсетей,
исключающий RFC1918 — сгенерировать можно любым калькулятором AllowedIPs.

## Управление устройствами на узле

```bash
ssh eu-vpn-hub

# AmneziaWG-зона
sudo vpn-peer --awg list
sudo vpn-peer --awg add <имя>
sudo vpn-peer --awg show <имя>     # клиентский конфиг в stdout
sudo vpn-peer --awg qr <имя>       # QR для телефона
sudo vpn-peer --awg revoke <имя>

# WireGuard-зона (без --awg)
sudo vpn-peer list
sudo vpn-peer add <имя>
```

Обе зоны управляются одним инструментом; зону Workout он не трогает.

## Как забрать конфиг нового устройства

`add` готового файла не оставляет: на узле хранятся только ключи и блок
`[Peer]` в серверном конфиге, а клиентский конфиг собирает `show`. Чтобы
перенести устройство на другую машину:

```bash
sudo vpn-peer --awg show work-pc > ~/work-pc.conf
```

Затем с целевой машины `scp odmen@31.58.181.202:~/work-pc.conf .` и импорт в
клиент AmneziaWG. Файл содержит приватный ключ — после переноса удалить его с
узла. Если peer не находится, проверить имя: `sudo vpn-peer --awg list`.

Имя устройства — произвольный идентификатор, он нужен только чтобы отличать
peer'ы в `list` и указывать в `show` / `qr` / `revoke`. Ограничение:
`^[a-z0-9][a-z0-9-]{0,30}$` — строчные латинские буквы, цифры и дефис, начинается
с буквы или цифры, до 31 символа.

```text
my-work-pc    OK          MyPC          отклонено (заглавные)
mobilko       OK          my pc         отклонено (пробел)
phone-wife    OK          wifes_phone   отклонено (подчёркивание)
2mobile       OK          мобилка       отклонено (не латиница)
```

Ограничение не косметическое: имя подставляется в имена файлов ключей и в
маркер `# peer: awg <имя>` внутри конфига, по которому инструмент находит и
удаляет блок. Пробелы и спецсимволы там ломали бы разбор.

## Что этот VPN не даёт

Доступа к Workout staging. Для personal-устройств закрыты PostgreSQL, Redis,
MinIO, backend, frontend, SSH `192.168.1.3`, Docker-сеть `172.18.0.0/16` и зона
`10.10.10.0/24`. Зоны изолированы и друг от друга: AmneziaWG-peer не видит
WireGuard-зону и наоборот. Проверено по каждому пункту, см. §8 и §10 основного
отчёта.
